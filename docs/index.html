浏览器插件 · KeePass · 本地优先

本地优先的 KeePass 密码库
在 Chrome 与 Edge 里安静工作

Monica KeePass 是一个浏览器插件，把加密的 .kdbx 密码库留在你的本机，再补上浏览器自动填充、Windows Hello 解锁、强密码生成和 OneDrive 备份/同步。没有插件服务端账号，密码库文件始终由你掌控。

功能

围绕本地 KeePass 密码库构建的浏览器能力。

本地优先的 KeePass .kdbx

导入或创建 KeePass 兼容的 .kdbx 密码库。文件始终加密保存在本机，由你的主密码与 key 文件保护。

Windows Hello 解锁

密码库在本机登记后，可用 Windows Hello 快速解锁。凭据只在本机加密保存，不需要额外网络账号。

主密码与本地 key 文件

支持主密码、key 文件，以及在本机记住 key 文件。组合 KeePass 原生凭据方式，不改变文件格式。

自动填充

浏览器自动填充采用更接近安卓端的 URL 匹配：精确域名、父子域名、同主域名。登录时少切换，少出错。

手动选择账号填充

网页输入框旁提供手动搜索与选择账号的按钮。一个站点多账号，或自动匹配不准时，随时手动填充。

强密码生成

在插件弹窗和密码输入框旁一键生成强密码。长度与字符集可控，生成结果不离开本机。

OneDrive 备份与同步

内置 Microsoft Client ID，设置页直接连接 OneDrive，浏览文件夹选择 .kdbx 初始化；支持拉取远端、上传本地与 KeePass 原生 merge 同步。

开源 GPL-3.0

基于 KeePass 生态与 kdbxweb，源码公开，采用 GPL-3.0-only，与 Monica 安卓参考项目保持一致。

OneDrive 与 KeePass 工作流

把本地密码库放进可备份、可同步的循环里。

1

导入或创建本地 .kdbx

用主密码（和 key 文件）创建密码库，文件加密保存在本机。Windows Hello 可在登记后用于快速解锁。

2

连接 OneDrive

设置页直接连接 OneDrive（内置 Microsoft Client ID），浏览 OneDrive 文件夹，选择 .kdbx 初始化本地库。

3

拉取 / 上传 / 同步

拉取远端更新、上传本地改动，或用 KeePass 原生 merge 合并两端。通过 Graph 文件元数据的 ETag/cTag 判断远端变化。

4

避免盲目覆盖

本地保存 base hash，冲突场景下不会盲目覆盖远端密码库。同步流程参考了安卓端的实现方式。

本地优先与安全

密码库文件始终在你手里。

没有插件服务端账号

插件不提供也不要求独立的服务端账号。密码库是标准 KeePass .kdbx 文件，加解密发生在本机。

Windows Hello 仅限本机

Windows Hello 解锁所需的凭据只在本机加密保存，不会上传。登记与解锁都在你的设备上完成。

同步由你选择

OneDrive 是可选的备份与同步通道。即使不使用，本地密码库、自动填充、密码生成等核心功能照常工作。

标准格式，可移植

使用标准 KeePass .kdbx，可与其他 KeePass 客户端互操作。OneDrive 同步基于 KeePass 原生 merge，不发明私有格式。

安装

面向开发者与参考构建的本地加载方式。

  1. 从仓库克隆代码，或在 Releases 获取已打包产物。
  2. 开发者构建：
    pnpm install
    pnpm run build
  3. 打开 chrome://extensions/（或 Edge 的 edge://extensions/）。
  4. 启用「开发者模式」。
  5. 「加载已解压的扩展程序」，选择目录：
    extension/.output/chrome-mv3

关于 OneDrive

插件使用 chrome.identity.launchWebAuthFlow 接入 Microsoft identity，并通过 Graph Files.ReadWrite 读写 OneDrive 中的 .kdbx。

当前重定向地址会显示在插件设置页的 OneDrive 区域。连接后选择 .kdbx 即可初始化本地库。
